Data Flow

CSV files → ingest_service.py cleans & time-weights → upsert to Supabase match_results table → feature_service.py engineers rolling features + Elo.

ML Pipeline

Feature columns defined once in feature_columns.py. Training uses TimeSeriesSplit + RandomizedSearchCV. Model saved as rf_epl_model.joblib.

API Endpoints

POST /api/v1/predict — real-time prediction.
POST /api/v1/pipeline/ingest — background ingestion.
POST /api/v1/pipeline/train — retrain model.

Supabase Table

Run data/supabase_schema.sql once in your Supabase SQL editor. UNIQUE constraint on (season, date, home_team, away_team) prevents duplicates on re-ingest.

Quick Start

1cp .env.example .envFill Supabase credentials
2pip install -r requirements.txt
3python scripts/validate_csv.py data/raw/seasons/Check your CSVs
4python scripts/ingest_seasons.pyLoad all 15 seasons → Supabase
5python scripts/train_model.pyTrain RF model
6uvicorn app.main:app --reloadStart API → localhost:8000/docs
